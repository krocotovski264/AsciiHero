# ASCII Hero — beta 0.8

ASCII-3D MMORPG prototype (medieval). Character creator + first location (tavern), Motion Matching locomotion.

## Structure
- `dist/` — ready builds: `index.html` (whole game in one file, opens in a browser) and `AsciiHero-beta-0.8.apk`.
- `game/` — game source (JavaScript, three.js):
  - `src/main.js` — UI, scene, camera, controls, world mode
  - `src/ascii.js` — GPU ASCII renderer (glyph shader, edges, bloom), materials
  - `src/human.js` — MakeHuman body: variants, skeleton, skinning, body-fitted garments
  - `src/character.js` — armour, hair, weapons, shield
  - `src/pose.js` — base poses (grip, shield, stance)
  - `src/anim.js` — Motion Matching + inertialization + foot IK
  - `src/tavern.js` — tavern location, lights, colliders, wall cut-away
  - `src/data_human.js`, `src/data_mm.js` — baked data (generated by the pipeline)
- `pipeline/makehuman/bake.py` — bakes MakeHuman base mesh + morph targets + skeleton -> `human.bin.gz/json`
- `pipeline/mocap/` — BVH retargeting (`retarget.py`), clip library (`lib2.py`), Motion Matching database (`mm_db.py`)
- `pipeline/apk/` — hand-made DEX (`mkdex.py`), manifest, signing key `hero.jks` (password `asciihero`, alias `hero`). Keep the key: updates must be signed with the same key.
- `android/AsciiHero/` — Android Studio project (WebView wrapper). `app/src/main/assets/index.html` = the game.

## Build the game
```
cd game
npm install                      # three, esbuild
bash build.sh                    # -> build/index.html (edit paths inside build.sh to your folder)
```
## Regenerate data (optional)
1. MakeHuman data: `git clone --depth 1 https://github.com/makehumancommunity/makehuman` -> set `MH` path in `pipeline/makehuman/bake.py`, run it, then `python3 game/mkdata.py`.
2. Mocap BVH: put the clips into a folder -> set the `BVH_DIR` path in `retarget.py` (and `D` in `cuts.py`), run `python3 mm_db.py`
Scripts contain absolute paths from the build machine (/home/claude/...) — adjust them.

## APK
Easiest: open `android/AsciiHero` in Android Studio -> Build APK.
Hand-made route (no SDK): `python3 pipeline/apk/mkdex.py classes.dex`, compile the manifest with `pyaxml`, zip with `assets/index.html`, sign with `jarsigner` (see commands used: v1 signature, targetSdk 29).
