# AsciiHero · первая локация · тестовые диалоги
# Формат (его же читает игра):
#   === id | уровень | режим | название
#       уровень: T0 реплика, T1 на ходу, T2 мягкое ведение, T3 полная сцена
#       режим: A ведёт игрок, B ведёт игра (см. диздок «Диалоги в движении»)
#   Говорящий: реплика
#   @действие — что делает игра (анимация, урон, предмет, флаг)
#   ? вопрос | вариант 1 | вариант 2 | ... (по умолчанию первый, на ответ 6 с, игрок не останавливается)
#   [2] строка, которая звучит только при ответе 2
#   Пустая строка между сценами. Строки с # — комментарии.
