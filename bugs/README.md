# Баги и проблемы

Сюда кидаются скриншоты и видео с багами из игры.

- Заливать: на GitHub открыть папку `bugs` → **Add file → Upload files** (ветка `unity-port`).
- Имя файла можно сделать говорящим: `плащ-в-латах.mp4`, `дождь-за-героем.png`. Короткое пояснение можно написать в описании коммита или в чате.
- Сборку APK заливка сюда не запускает (сборка идёт только при изменениях в `Unity/`).
- Картинки и видео хранятся через Git LFS (как и остальные медиа в репозитории).

После исправления бага файл отсюда удаляется.
